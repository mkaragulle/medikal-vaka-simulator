V381 — Diğer Olgular Global Redesign

Scope:
- Reworked the “Diğer olgular” bottom case browser globally within the case page.
- Kept clinical case data, answer logic, feedback, scoring and medical content unchanged.
- Preserved horizontal virtualization and custom scrollbar behavior from the performance fixes.

Changed files:
- src/App.jsx
- src/components/CaseList.jsx
- src/index.css

What changed:
1. Bottom case browser shell was redesigned as a lighter “Olgu gezgini” rail.
2. Header structure was simplified and aligned.
3. Search/count toolbar was made flatter, smaller and less shadow-heavy.
4. Horizontal case cards were rebuilt into compact rail cards:
   - left status stripe
   - case index and point info
   - clean two-line title
   - compact difficulty/solved badge
   - short action label
5. Old bulky footer/topline styling is hidden only for the horizontal case rail.
6. Card width was reduced from 330px to 292px to show more cases in the same area.
7. Performance-friendly rules were kept: virtualization, no heavy shadows, stable custom scrollbar.
8. Dark mode support was added for the redesigned rail.

Notes:
- No case pool, diagnosis, option, feedback, or medical educational data was modified.
- Build was not run in this environment because node_modules/vite are not available in the sandbox.
