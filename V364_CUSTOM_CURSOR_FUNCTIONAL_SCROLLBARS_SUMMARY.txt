KlinikIQ V364 — Custom Cursor ile İşlevsel Custom Scrollbar Sistemi

Amaç:
- Scrollbar üzerine gelince Windows native cursor + KlinikIQ custom cursor çakışmasını kaldırmak.
- Custom cursor'ı scrollbar üzerinde gizlemek yerine, scrollbarları da custom cursor ile kullanılabilir hale getirmek.

Yapılanlar:
1. src/components/KlinikIQCustomScrollbars.jsx eklendi.
   - Native browser scrollbarları görsel olarak gizlenir.
   - Ana sayfa, modal/kutu/toolbox gibi scrollable alanlar için özel DOM tabanlı scrollbar overlay üretilir.
   - Scrollbar thumb sürüklenebilir; aşağı-yukarı ve yatay eksende scroll işlevi korunur.
   - Track alanına tıklayınca ilgili scroll pozisyonuna atlama davranışı çalışır.
   - Light/dark tema renkleri desteklenir.
   - Performans için scroll/resize update işlemleri requestAnimationFrame ile yapılır.
   - MutationObserver kendi scrollbar değişimlerini filtreler, gereksiz scan döngüsü azaltılır.

2. src/App.jsx güncellendi.
   - KlinikIQCustomScrollbars component'i PremiumCursor ile birlikte mount edildi.

3. src/components/PremiumCursor.jsx V364'e güncellendi.
   - Scrollbar alanında custom cursor gizleme mantığı kaldırıldı.
   - Custom scrollbar DOM elementleri [data-cursor="interactive"] ile cursor sistemine dahil çalışır.
   - Light/dark mode cursor renkleri, sekme geri dönüş recovery fix'i ve sade halka + nokta tasarımı korundu.

Beklenen sonuç:
- Scrollbar üzerinde Windows standart cursor görünmemeli.
- Scrollbar custom DOM overlay olarak görünmeli.
- Scrollbar sürükleme işlemi KlinikIQ custom cursor ile yapılabilmeli.
- Custom cursor scrollbar üzerinde donup kalmamalı.
