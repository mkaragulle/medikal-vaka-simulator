# KlinikIQ Hap Bilgi Çalış — Two Panel Redesign V92

## Scope
The Hap Bilgi Çalış screen was restructured into a two-panel flashcard workspace inspired by the approved mockup.

- Moved the main flashcard into a large left-side study stage.
- Moved filters, catalog actions, card actions, and learning decisions into a right-side control cockpit.
- Reduced scattered horizontal controls and made the screen feel like a single study workspace.
- Kept the existing top header and progress logic.
- Preserved existing card functionality, catalog menu, favorite/catalog actions, create/copy card actions, and learning decision buttons.
- Added responsive rules for narrower screens.
