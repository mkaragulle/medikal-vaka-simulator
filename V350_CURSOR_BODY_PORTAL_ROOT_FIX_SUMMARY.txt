KlinikIQ V350 — Cursor Body Portal Root Fix

Kök problem:
Önceki optimizasyonlardan sonra cursor React ağacı içinde main/app shell altında render ediliyordu ve aktifleşme koşulları fazla savunmacıydı. Bazı masaüstü tarayıcı/cihaz kombinasyonlarında custom cursor hiç görünmeden sistem native cursor ile kalabiliyordu.

Bu sürümde:
- PremiumCursor sıfırdan body portal mantığıyla yazıldı.
- Cursor DOM node doğrudan document.body içine ekleniyor.
- React state mouse hareketinde kullanılmıyor.
- requestAnimationFrame ile yalnızca transform güncelleniyor.
- pointer/hover/reduced-motion gating kaldırıldı; yalnızca gerçek touch pointer yok sayılıyor.
- Eski/yeni cursor çakışmasını önlemek için native cursor gizleme runtime CSS ile uygulanıyor.
- Input/textarea/select/contenteditable alanlarında klasik text cursor korunuyor.
- PerformanceOptimizer korunmuştur.
