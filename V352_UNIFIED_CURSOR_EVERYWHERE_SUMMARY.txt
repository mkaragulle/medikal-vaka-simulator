KlinikIQ V352 — Unified Cursor Everywhere Fix

Amaç:
- Premium cursor tasarımının nested glossary/toolbox, floating popover, normal kart, buton ve genel arayüzde aynı kalmasını sağlamak.
- Glossary word üzerine gelince native/standart cursor'a geri düşme problemini çözmek.

Yapılanlar:
1. src/components/PremiumCursor.jsx tamamen V352 unified sistemine geçirildi.
2. Eski cursor runtime style/node kalıntıları temizleniyor.
3. Cursor doğrudan document.body içine ekleniyor; parent layout, z-index veya portal sınırına takılmıyor.
4. html.ki-unified-cursor-active aktif olduğunda body içindeki tüm normal alanlarda native cursor gizleniyor.
5. Nested glossary popover, tooltip, toolbox ve data-glossary alanlarında cursor:none kuralı ekstra güçlendirildi.
6. Glossary hover modu her nested glossary term için korunuyor.
7. Mouse hareketi React state kullanmadan requestAnimationFrame + transform ile çalışıyor.
8. Input/textarea/select/contenteditable alanlarında klasik text cursor korunuyor.
9. Eski V349/V350/V351 cursor DOM/CSS kalıntılarının görünmesi engellendi.

Test edilmesi gereken yerler:
- Ana buton/kart hover

- Toolbox/popover içindeki nested glossary word hover
