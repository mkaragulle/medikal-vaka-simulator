1) Scroll CSS optimizasyonu
- Scroll/resize sırasında tüm DOM'u hedefleyen `*` selector kaldırıldı.
- Bunun yerine yalnızca pahalı kart, buton, panel, tooltip, topbar ve Hap Bilgi elemanlarını hedefleyen `:is(...)` selector listesi kullanıldı.
- Böylece scroll sırasında global style recalculation maliyeti azaltıldı.

2) Alt olgu araması optimizasyonu
- `useDeferredValue` App seviyesine eklendi.
- Alt olgu arama metni deferred hale getirildi.
- Recursive vaka search index artık yalnızca gerçekten arama sorgusu varsa oluşturuluyor.
- Boş aramada branch case pool doğrudan kullanılıyor; normal vaka gezintisinde gereksiz full-text index maliyeti yok.
- Seçili vakanın aktif havuzda olup olmadığı artık `.some()` yerine memoized `Set` ile kontrol ediliyor.

3) Yanıt işaretleme akıcılığı
- Normal çalışma modunda feedback görünümü önce local olarak açılıyor.
- App seviyesindeki stats/solved/wrong-answer güncellemesi bir sonraki macrotask'a bırakılıyor.
- Exam/strict modda yanıt kaydı senkron korunmuştur; sınav akışı bozulmamıştır.

4) Custom cursor optimizasyonu
- Kullanılmayan native scrollbar hit-test fonksiyonları temizlendi.
- Custom scrollbar üstünde olup olmama kontrolü hedef element değişmediği sürece cache'leniyor.
- Pointermove sırasında tekrar eden `closest()` maliyeti azaltıldı.
- Cursor tasarımı, text input davranışı ve scrollbar drag davranışı korunmuştur.

5) Custom scrollbar optimizasyonu
- Takip edilen maksimum scrollable element sayısı 56'dan 48'e indirildi.
- Pointer activity throttle 240ms'den 320ms'ye çıkarıldı.
- Tekrarlayan inline style yazımları `setStyleValue` ile yalnızca değer değiştiğinde uygulanır hale getirildi.
- MutationObserver attribute filter sadeleştirildi; `class` ve `data-theme` attribute gözlemi ana observer'dan çıkarıldı. Theme için ayrı observer zaten korunuyor.
- Scrollbar görünümü, drag davranışı ve overlay/top-layer mantığı korunmuştur.

6) GitHub-safe paketleme
- `.gitignore` genişletildi: zip, log, cache, coverage, tsbuildinfo gibi yerel/generate dosyalar dışarıda bırakılır.
- `GITHUB_UPLOAD_NOTES.txt` eklendi.
- Final zip hazırlanırken `node_modules`, `dist`, `.vite`, `.vercel`, cache ve log dosyaları dışarıda bırakıldı.

- `npm run build` başarılı.
