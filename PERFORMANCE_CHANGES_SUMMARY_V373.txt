KlinikIQ V373 Performance / Smoothness Changes

Changed files:
- src/components/PremiumCursor.jsx
- src/components/KlinikIQCustomScrollbars.jsx
- src/components/PerformanceOptimizer.jsx
- src/components/DiagnosisQuiz.jsx
- src/components/GlossaryTooltip.jsx
- src/components/TusPearlStudyScreen.jsx
- src/index.css
- PERFORMANCE_AUDIT_REPORT.md
- PERFORMANCE_CHANGES_SUMMARY.txt

1) Global observer lag reduced
- PremiumCursor no longer observes html/body class changes for theme detection.
- KlinikIQCustomScrollbars no longer observes html/body class changes for theme detection.
- Theme observers now track data-theme only, while storage events still refresh theme when needed.
- This prevents normal scroll-state classes such as ki-is-scrolling and route-transitioning from waking cursor/scrollbar theme logic.

2) Custom scrollbar cost reduced
- Top-layer occlusion rect cache was extended from 180 ms to 420 ms.
- Theme changes now only request a visual update instead of scheduling a full scrollbar scan.
- Existing custom scrollbar behavior, drag behavior, modal/dropdown/tooltip layering and subtle style are preserved.

3) Scroll-state class churn reduced
- PerformanceOptimizer now tracks whether scrolling is already active.
- It avoids repeatedly clearing/recreating the scroll-idle timeout on every scroll tick.
- The scroll performance class remains active slightly longer but mutates the DOM less frequently, which reduces micro-stutter.

4) Answer submit / feedback mount smoothed
- DiagnosisQuiz now marks the answer as submitted immediately, but mounts the heavy detailed feedback panel on the next animation frame inside a transition.
- A lightweight “Yanıt işleniyor” placeholder is shown only during that tiny handoff.
- Correct/wrong logic, exam-mode behavior, feedback text and scientific content are preserved.

5) Glossary re-render pressure reduced
- GlossaryText now uses a custom memo comparator instead of shallow default memoization.
- Text, reveal mode, maxTerms, branch, nesting and array-like glossary parameters are compared by semantic signature.
- Glossary parsing cache is still preserved; glossary content and nested glossary behavior are not removed.

6) Catalog/library list row rendering improved
- Catalog row and addable library row markup were extracted into memoized row components.
- Row-level edit/add/remove/delete handlers are stabilized through row-local callbacks and parent callback wrappers.
- V370/V372 48-card visible limit, search reset, source filter, “Daha fazla göster”, delete popover and catalog membership Set logic are preserved.

7) CSS scroll smoothness polish
- Added V373 guardrails to reduce layer churn during scrolling.
- Dense list rows and answer/branch cards no longer keep unnecessary will-change promotion while idle/scrolling.
- During active scroll, card-row transforms are suppressed to avoid GPU layer churn.
- Tooltip/delete/source dropdown transition properties remain transform/opacity-based and short.
- Glossary hover visual effects are only softened during active scrolling; glossary interaction itself remains enabled.

8) Explicitly preserved behavior
- Medical/TUS case data, correct answers, feedback, explanations, glossary entries and scientific text were not changed.
- TUS mode and KOMİTE mode remain intact.
- Custom cursor remains enabled.
- Custom scrollbar remains enabled.
- Glossary tooltip, hover delay, click/nested glossary behavior remain intact.
- Dark/light mode styling is preserved.
- Kataloglarım, Tüm kartlardan ekle, search/filter, more loading, delete confirmation and card editor flows are preserved.

Validation:
- npm install --no-audit --no-fund: successful.
- npm run build: successful.
- Build completed with expected large chunk warnings for case-bank and glossary chunks; no syntax/import/build failure remained.

Expected user-facing result:
- Less scroll-related cursor/scrollbar micro-stutter.
- Faster-feeling answer selection and feedback opening.
- Smoother Kataloglarım / Tüm kartlardan ekle browsing.
- Lower chance of popup/dropdown/cursor/scrollbar layers waking expensive measurement paths during normal navigation.
