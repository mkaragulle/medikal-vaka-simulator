Ek render optimizasyonları:
- CaseListItem artık selectedCaseId yerine sadece kendi selected boolean değerini alıyor.
- Vaka kartları arasında geçişte tüm yatay listenin re-render baskısı azaltıldı; yalnızca eski/yeni seçili kartın görsel durumu değişir.
- App.jsx içinde aktif branch vaka üyelik kontrolü için memoized Set eklendi.
- selectedCase ve branch geçerlilik kontrollerinde .some() yerine Set.has() kullanıldı.

Arama performansı:
- Vaka arama için WeakMap tabanlı CASE_SEARCH_META_CACHE eklendi.
- Her vaka objesinin normalize edilmiş title/keyword/question/fullText alanları bir kez hesaplanır.
- Alt vaka arama inputu useDeferredValue ile düşük öncelikli filtrelemeye alındı.
- Kullanıcı yazarken input tepkisi daha hızlı kalır; ağır recursive collect/normalize işlemleri tekrar tekrar yapılmaz.

Hap Bilgi / Katalog performansı:
- filteredCards.map(id).join('|') ile tüm liste imzası üretme kaldırıldı.
- filteredCardsSignature daha hafif uzunluk/ilk/orta/son id + filtre/set boyutu mantığına çekildi.
- filteredCardIdSet ayrı memoize edildi; sessionCards içinde tekrar tekrar Set oluşturma azaltıldı.
- branchOptions hesaplamasında branches x allCards.some döngüsü yerine allCardsBranchIdSet kullanıldı.
- aktif kart katalog üyeliği activeCatalog.cardIds.includes yerine activeCatalogCardIdSet.has ile kontrol ediliyor.

Glossary optimizasyonları:
- Tooltip açılışında aynı frame içinde çalışan çift requestAnimationFrame konumlandırma çağrısı teke indirildi.
- Glossary split cache limiti 600'den 900'e çıkarıldı.
- Tooltip, nested glossary ve pre/post answer davranışları korunmuştur.

Custom scrollbar optimizasyonları:
- MAX_TRACKED_ELEMENTS 48'e indirildi.
- Top-layer rect cache 220ms'ye çıkarıldı.
- Pointer activity throttle 320ms'ye çıkarıldı.
- MutationObserver artık body altında yüksek frekanslı class/style değişimlerini izlemiyor.
- Observer open/hidden/aria-expanded/data-scrollable/data-scroll-container ve childList değişimlerini takip etmeye devam eder.
- Drag, overlay, modal/dropdown occlusion ve scrollbar görünümü korunmuştur.
