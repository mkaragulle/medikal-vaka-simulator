# KlinikIQ V62 — Unified TUS / Komite Hero Layout

## Scope
This update makes the Komite dashboard hero match the TUS hero frame, proportions, spacing, visual language, and right-side action panel rhythm.

## Updated
- TUS and Komite hero cards now share the same max-width, border radius, padding, background treatment, shadow, and general proportions.
- Komite hero title changed to **KlinikIQ Komite**.
- Komite kicker changed to **Komite çalışma alanı**.
- Komite subtitle updated with concise Turkish product copy.
- Komite tags simplified to three compact pills: **Ders anlatımı**, **Soru üretimi**, **Hap kartlar**.
- Komite right panel rebuilt in the same style as the TUS action panel:
  - **Materyal yükle**
  - **Çalıştıklarım**
  - **Tekrar merkezine git**
- Existing event handlers and navigation behavior are preserved.

## Preserved
- TUS case flow
- Komite upload/material workflow
- AI generation logic
- Scoring/statistics logic
- Review and card logic
- Global top bar behavior
