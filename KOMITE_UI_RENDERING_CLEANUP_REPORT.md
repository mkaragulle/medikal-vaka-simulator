# KOMITE UI Rendering Cleanup

This update changes only neutral presentation behavior in the KOMITE lesson view.

Changes:
- Cleaner lesson cards with improved spacing, typography, and readable line length.
- Learning objective intro text is displayed as a lead sentence, not as a bullet.
- Bullet-like inline text is rendered as real bullet lists.
- Continuation sentences after bullet lists are separated into normal paragraphs.
- Markdown-style bold labels are rendered visually instead of shown as raw symbols.
- Main section cards and summary blocks were visually polished for light and dark themes.

No subject-specific trigger words, topic detectors, or hardcoded educational concepts were added.
