KlinikIQ V351 — Premium Cursor Lens Redesign

Bu sürümde cursor tasarımı sıfırdan yeniden yapıldı.

Ana değişiklikler:
- Eski crosshair/sert halka tasarımı kaldırıldı.
- Yeni tasarım: küçük, rafine, cam/lens hissi veren mint medikal cursor.
- Default mod: hafif lens + mikro merkez noktası + soft mint halo.
- Interactive mod: buton/kart/link üzerinde cursor yumuşak büyür ve daha premium bir lens formuna geçer.
- Glossary mod: cursor küçük bilgi rozetiyle görünür, eski cursor ile çakışmayı azaltır.
- Loading mod: minimal dönen progress halkası korunur.
- Text/input alanlarında klasik text cursor korunur.
- Mobilde custom cursor kapalı kalır.

Performans koruması:
- Mouse hareketinde React state kullanılmaz.
- Cursor document.body üzerinde çalışır.
- Pozisyon sadece requestAnimationFrame + transform ile güncellenir.
- Pointer/mouse eventleri sadeleştirildi; çift pointermove + mousemove dinleme kaldırıldı.
- Eski V350/önceki cursor class kalıntıları başlangıçta temizlenir.
