# GitHub upload note

This ZIP is prepared with the project files at the ZIP root. After extracting, `package.json`, `src/`, `api/`, and `public/` should be directly visible in the extracted folder.

Recommended upload flow:
1. Extract this ZIP.
2. Open the extracted folder.
3. Copy/upload the visible contents, not the outer folder if your repository already exists.
4. Do not upload `node_modules` or `dist`.
