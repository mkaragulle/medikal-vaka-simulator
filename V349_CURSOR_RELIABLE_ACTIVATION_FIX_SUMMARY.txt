KlinikIQ V349 — Cursor Reliable Activation Fix

Problem:
- V348 cursor bazı sistemlerde hiç görünmeyebiliyordu.
- Sebep büyük olasılıkla fazla katı pointer/hover capability kontrolü, cursor DOM'unun enabled=false iken render edilmemesi ve scroll performans modunun cursor'ı gizlemesiydi.

Yapılan düzeltmeler:
1. src/components/PremiumCursor.jsx sıfırdan güvenli biçimde yeniden yazıldı.
   - Cursor artık her zaman DOM'da render edilir.
   - İlk gerçek desktop mouse hareketinde aktif olur.
   - React state kullanılmaz; mouse hareketinde sadece ref + requestAnimationFrame kullanılır.
   - pointermove ve mousemove birlikte dinlenir.
   - Desktop/touch destekli laptoplarda kapanma riski azaltıldı.

2. src/index.css içindeki cursor CSS'i V349 ile değiştirildi.
   - Daha görünür clinical crosshair/lens tasarımı eklendi.
   - Native cursor runtime style ile güçlü biçimde gizlenir.
   - Text input/textarea/select alanlarında klasik text cursor korunur.
   - Glossary hover'da i modu, loading'de spinner modu korunur.

3. Performance scroll modu cursor'ı artık zorla gizlemez.
   - Önceki sürümlerde scroll state takılı kalırsa cursor hiç görünmüyormuş gibi davranabiliyordu.

Deploy sonrası test:
- Vercel deploy bittikten sonra Ctrl+Shift+R ile hard refresh yap.
- Desktop Chrome/Opera üzerinde mouse hareket ettirince imleç görünmelidir.
- Glossary word üstünde eski cursor + yeni cursor çakışması olmamalıdır.
