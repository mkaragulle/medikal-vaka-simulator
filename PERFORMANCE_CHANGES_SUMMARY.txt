What changed:

1. Re-render / interaction priority reduced
- Answer submission now returns the score immediately and moves App-level solved-case, wrong-answer, session-stat, and exam-state updates into React `startTransition`.
- This keeps the local answer/feedback interaction more responsive while preserving existing scoring and history behavior.

2. Catalog / large list rendering made lighter
- `Tüm kartlardan ekle` no longer builds a full search index for every card when the search query is empty.
- Source filtering is separated from query matching.
- Search text is generated lazily only when the user actually types a search query.
- Per-card search text is cached with `WeakMap`, so repeated searches do not repeatedly join/lowercase the same card fields.
- The existing 48-card visible limit and “Daha fazla göster” behavior are preserved.

3. Glossary setup cost reduced
- `GlossaryText` now checks whether the source text is likely to contain glossary candidates before resolving the full glossary term pool.
- Existing split cache, nested glossary behavior, hover/click intent, and glossary content are preserved.
- Tooltip position updates now avoid redundant `setPosition` when computed coordinates are effectively unchanged.

4. Custom cursor optimized
- Custom cursor was not removed.
- Repeated custom-scrollbar hover checks now cache the last pointer target before calling `closest()` again.
- Cursor state for text inputs, custom scrollbar drag, and interactive elements is preserved.

5. Custom scrollbar optimized
- Custom scrollbar was not removed.
- Repeated inline style writes for track/thumb position and size now happen only when values actually change.
- Generic `section` was removed from the scrollable candidate selector to reduce broad DOM scanning.
- Anonymous focus/pageshow listeners were replaced with named handlers so cleanup is deterministic.
- Existing z-index/top-layer handling, drag behavior, subtle styling, and native-scrollbar replacement are preserved.

6. Storage write cost reduced
- `writeDeferred()` now defers JSON serialization together with the actual localStorage write.
- Reads still return pending in-memory values correctly before the deferred write is flushed.
- Pagehide/beforeunload/hidden-tab flush behavior is preserved.

7. CSS scroll-time cost reduced
- Broad `html.ki-performance-mode.ki-is-scrolling *` and resize `*` selectors were replaced with targeted component selectors.
- Costly `[style*="filter"]` selector was removed and replaced with explicit known glow/pulse/orb selectors.
- Existing premium look remains in normal state; heavy effects are still reduced during scroll/resize/route transition.
