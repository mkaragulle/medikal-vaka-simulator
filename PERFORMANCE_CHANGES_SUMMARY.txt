KlinikIQ V372 Performance / Smoothness Changes Summary

Render optimizasyonları:
- CaseList satırları memoized CaseListItem bileşenine taşındı.
- CaseList içinde liste başlıklarında GlossaryText kaldırıldı; düz metin kullanıldı. Esas eğitim/vaka/feedback metinlerindeki glossary davranışı korunmuştur.
- Horizontal CaseList reset key artık tüm listeyi büyük string olarak map/join yapmıyor; length + first id + last id + solved count ile daha hafif hesaplanıyor.
- TusPearlStudyScreen içinde katalog satırları memoized CatalogCardRow bileşenine taşındı.
- Katalogdaki kartlar ve Tüm kartlardan ekle satırları için inline JSX ve inline callback üretimi azaltıldı.
- Katalog görünür kart limiti 48 olarak korundu; daha fazla göster davranışı korunmuştur.

Liste performansı:
- Tüm kartlardan ekle listesinde sade metin yaklaşımı korundu.
- Katalog satırlarına content-visibility ve contain-intrinsic-size eklendi.
- CaseList itemlarına content-visibility eklendi.
- Aktif katalog membership kontrolünde mevcut Set kullanımı korundu.

Custom scrollbar optimizasyonları:
- MAX_TRACKED_ELEMENTS 72’den 56’ya düşürüldü.
- body * genel taraması yerine bilinen scrollable/container selector havuzu kullanıldı.
- Scrollbar pointer activity throttle 120ms’den 240ms’ye çıkarıldı.
- Top-layer rect cache süresi 90ms’den 160ms’ye çıkarıldı.
- MutationObserver sonrası scan gecikmesi 140ms’den 220ms’ye alındı.
- Drag sırasında tarama durdurma davranışı korundu.
- Modal/dropdown/tooltip/top-layer occlusion kontrolü korunmuştur.

Premium cursor optimizasyonları:
- Custom scrollbar targetları için ucuz closest tabanlı state kontrolü eklendi.
- Scrollbar üzerinde cursor/pointer state daha kararlı hâle getirildi.
- Cursor transform/opacity tabanlı çalışmaya devam eder.
- Cursor kaldırılmadı; tasarım hissi korunmuştur.

Storage optimizasyonları:
- localBackend içine writeDeferred ve flushDeferredWrites eklendi.
- Büyük/tekrarlayan stats, solved cases, exam history, product mode, AI stats/filter yazımları idle/debounce ile ertelenir.
- pagehide, beforeunload ve visibilitychange sırasında pending yazımlar flush edilir.
- Tema ve kritik login/register/current user işlemleri immediate write davranışını korur.

CSS performans optimizasyonları:
- html.ki-is-scrolling, html.ki-is-resizing ve html.ki-route-transitioning aktifken ağır box-shadow/backdrop-filter/animation maliyeti geçici olarak azaltıldı.
- Normal durumda premium görünüm korunur; efekt azaltma yalnızca scroll/resize/route geçişi sırasında devreye girer.
- Katalog ve vaka satırlarında scroll sırasında hover transformları durduruldu.

Bilinçli korunan davranışlar:
- TUS ve KOMİTE modları.
- Tıbbi içerik, soru metinleri, cevaplar, option feedbackleri ve glossary data.
- Glossary tooltip ve nested glossary sistemi.
- Custom cursor ve custom scrollbar.
- Dark/light mode renk sistemi.
- V371’deki 48 kartlık görünür limit ve arama sonrası reset davranışı.
