# V142 Feature Card Professional Spacing Update

The V141 forced negative spacing was replaced with a balanced professional rhythm:

- Removed negative margins and translateY overlap from feature card headings/descriptions.
- Kept the title and description visually close with a controlled 4–5px flex gap.
- Restored safe line-height values so multi-line titles such as “Akıllı Gelişim Raporları” never collide with the body text.
- Preserved the compact card system with slightly more premium breathing room.
- Added desktop, short-height desktop, tablet, and mobile overrides.
